# Third-Party Boundary

## Included Third-Party Content

None are vendored. Original `kernel/lab_echo.c` is part of this repository; Ubuntu Linux headers, compilers, QEMU and runtime libraries are installed from the distribution only in CI. No third-party source code, binaries, images, fonts, course notes, vendor SDK files, root filesystem images or toolchains are committed.

## Referenced Technologies

Linux, U-Boot, Buildroot, Ubuntu, Qt, Rockchip and related component names appear only as factual references to the reviewed system path. Their source and binary distributions are not included and remain governed by their respective upstream or vendor terms.

## Source-Material Boundary

The private source-material directory was used only for read-only inventory and technical-scope analysis. Its course files, external images, XMind data, generated build outputs and unknown-rights code are not part of this repository.

Neither license changes the rights of Linux or historical course/vendor material. See [source provenance](docs/source-provenance.md).
